# R49 Mobile Login No-Scroll + Image Deterrence

- Mobile login uses one dynamic viewport height and does not page-scroll.
- Hero image is rendered as a CSS background rather than a direct `<img>` target.
- Context-menu and drag actions are blocked on the login visual as a download deterrent.
- This is deterrence only: no web app can technically prevent screenshots, developer tools, or determined copying of assets already delivered to the browser.
- Desktop/tablet/mobile layouts preserve responsive sizing.
