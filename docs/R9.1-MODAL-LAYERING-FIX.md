# R9.1 Modal Layering Fix

- Removed transform-based route/page entrance animation that could create a stacking context under sticky headers.
- Added explicit global z-index layers for sidebar, topbar, search results, modal backdrop and dialog.
- Modal overlays now cover the complete dynamic viewport and safe-area insets.
- Tall dialogs scroll internally and remain fully visible on phones/tablets/desktops.
- Mobile dialogs start below the safe-area and no longer render behind the sticky topbar.
