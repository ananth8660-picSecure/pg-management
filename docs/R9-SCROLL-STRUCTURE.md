# R9 — Smooth Scroll & Unlimited Property Structure

- Window/body is the single primary vertical scroll surface.
- Mouse wheel gets gentle easing; trackpad/touch retain native scrolling.
- Sidebar, tables, room strips and modals remain independently scrollable when needed.
- Scrollbars stay visually hidden without disabling scrolling.
- Owner can add Blocks, Floors, Rooms and Beds repeatedly.
- New rooms accept any positive initial bed count.
- Existing rooms can add beds later; only vacant beds can be removed.
- Floor header has a direct + Room action and each block has + Add Floor.
- Room amenities remain editable independent of bed count.
