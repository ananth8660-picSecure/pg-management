# R41.3 Startup Watchdog Fix

- Added an HTML startup fallback visible before Angular bootstraps.
- Added global startup error/unhandled-rejection surface so failures no longer look like a blank white page.
- Added a 4.5 second Firebase Auth startup watchdog so the UI cannot wait forever for Auth initialization.
- Added an 8 second signed-in profile/Firestore bootstrap timeout.
- A delayed Firebase callback may still complete later and restore the authenticated workspace.
- No Firebase rules, Functions, or R2 deployment is required for this frontend-only patch.
