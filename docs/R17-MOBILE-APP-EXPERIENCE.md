# R17 Mobile App Experience

- Mobile web now uses an app-style shell instead of a compressed desktop layout.
- Persistent bottom tabs: Home, Residents, Vacancy, Rent, More.
- More opens the full role-filtered navigation drawer.
- Every module uses a semantic icon rather than generic repeated icons.
- Compact mobile app bar, search row, notification control and profile avatar.
- Safe-area handling for notches, gesture bars, foldables and landscape phones.
- Touch-friendly controls and native momentum scrolling with invisible scrollbars.
- Desktop keeps the premium sidebar + command-center workspace.
- Web app manifest enables standalone/home-screen presentation where supported.
- Owner/Manager permissions remain enforced in both sidebar and mobile navigation.
