# R15 Reports Center

R15 replaces the generic reports shell with a live reports center.

Reports included:
- Occupancy by block / floor / room
- Exact vacancy report down to bed level
- Current-month rent collection status
- Resident stay-history report
- Room and amenity inventory report

Each report supports search, block filtering where relevant, CSV export, and print-friendly layout.
Manager accounts can access operational reports when the Owner enables Reports access, but aggregate financial values remain Owner-only.
