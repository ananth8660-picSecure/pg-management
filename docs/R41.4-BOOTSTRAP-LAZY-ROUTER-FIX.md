# R41.4 Bootstrap / Lazy Router Fix

Root startup was importing the full authenticated shell, notification stack, app lock, and all pages before Angular could mount the root component. This made any module-level runtime failure look like a permanent white/startup screen.

Changes:
- Root component now imports only RouterOutlet + AuthService.
- Login, shell, and all feature pages use lazy route loading.
- Shell owns its own nested RouterOutlet and app-lock screen.
- Unauthenticated navigation routes to /login.
- Successful login routes to the workspace.
- 10-second pre-Angular watchdog now surfaces bundle/bootstrap failures instead of spinning forever.
- Added a `[PG Ops] main.ts loaded` console marker to distinguish bundle-load failure from Firebase/auth failure.

No Firebase, Firestore, Functions, or R2 schema changes are included in this patch.
